# Forge3D — tienda inicial

Esta carpeta contiene una primera versión visual e interactiva de Forge3D.

## Cómo abrirla
1. Descarga `forge3d.zip` y descomprímelo.
2. Abre `index.html` en un navegador para probar la tienda.

## Incluye
- Diseño adaptable a móvil y computadora.
- Catálogo de demostración con búsqueda, categorías y orden.
- Detalles de productos con selección de color y tamaño.
- Carrito persistido en el navegador.
- Solicitudes de pedido de demostración, sin cobro.
- Formulario de diseño personalizado.
- Formulario de contacto y suscripción de demostración.
- Panel de demostración con exportación de datos locales.
- Aviso de cookies y secciones informativas.

## Importante
Esta versión es un prototipo frontend. Los datos se guardan solo en el navegador; no hay servidor, base de datos compartida, autenticación real, correo real, PayPal, cálculo de impuestos ni integración de transportistas. El botón Admin no está protegido y no debe usarse con datos privados. Antes de vender, hace falta construir y desplegar un backend seguro, configurar un dominio, las credenciales de proveedores y revisar políticas legales y fiscales.

Los productos, imágenes vectoriales, precios y reseñas son ejemplos de demostración. Sustitúyelos por productos reales y no publiques testimonios ficticios.
